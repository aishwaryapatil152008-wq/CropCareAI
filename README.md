
# 🌱 Smart AI Crop Health

### 🤖 AI-Powered Crop Disease Detection & Plant Health Assistant

Smart AI Crop Health is a simple, attractive, and farmer-friendly web application concept designed to help users monitor crop health, upload leaf images, explore crop disease assessments, and access crop-care guidance.

The project features a responsive interface with a green-and-white theme, user registration and login demo, crop selection, image upload, scan history, multilingual interface, dark mode, and a crop-care assistant.

## ✨ Features

- 🏡 **Landing Page** — Clean introduction with a Get Started button.
- 🔐 **Login & Registration** — Demo account creation and login.
- 👤 **User Profile** — Display and update the user's name.
- 📸 **Leaf Image Upload** — Select a leaf photo from a device or use a supported camera input.
- 🌾 **Crop Selection** — Choose Tomato, Potato, Rice, Maize, or Cotton.
- 🧪 **Disease Assessment Interface** — Display sample crop assessment results.
- 📋 **Scan History** — View previous demo assessments.
- 🤖 **AI Crop Assistant** — Get predefined answers to common crop-care questions.
- 🌐 **Multilingual Interface** — English, Hindi, and Marathi UI translations.
- 🌙 **Dark Mode** — Switch between day and night themes.
- 📱 **Responsive Design** — Adapt the layout for mobile phones, tablets, and desktops.

## 🚀 Getting Started

### 1. Download or Clone the Project

Clone the repository if it is hosted on GitHub:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Alternatively, download the project ZIP and extract it.

### 2. Open in Visual Studio Code

Open VS Code, select **File → Open Folder**, and choose the project folder.

### 3. Check the Files

Ensure that the project contains:

- `index.html`
- `style.css`
- `script.js`

Check that the HTML file correctly links to the stylesheet and JavaScript file.

### 4. Run the Website

Recommended method:

1. Install the Live Server extension in VS Code.
2. Open `index.html`.
3. Right-click inside the editor.
4. Select **Open with Live Server**.

The website should open in your default browser.

## 🔬 How It Works

1. Open the website landing page.
2. Register a demo account or log in.
3. View your personalized dashboard.
4. Select Scan to open the crop assessment page.
5. Take a photo or upload a leaf image.
6. Choose the relevant crop.
7. Click **Analyze with AI**.
8. View the sample assessment and recommended crop-care guidance.
9. Review previous assessments in History.
10. Ask general crop-care questions using the Assistant.
11. Change the interface language or theme in your settings.

## ⚠️ Current Limitations

This version is a **frontend prototype**. It demonstrates the user interface and basic browser-side interactions.

- Real AI-based crop disease detection is not yet integrated.
- Sample assessment results are not generated from the uploaded image.
- The crop assistant uses predefined responses rather than a live AI model.
- Authentication is not secure enough for production use.
- Demo data is stored in the browser and may be lost if browser storage is cleared.
- The current interface does not include a backend database or cloud synchronization.

**Security warning:** Do not use real passwords or sensitive personal information in this prototype. Production authentication must be implemented on a secure backend with proper password hashing and session management.
